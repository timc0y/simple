## Simple

Invoke `$simple` and read the nearest `SIMPLE.md` before architecture, ownership, compatibility, migration, deletion, or broad refactoring decisions. Also use Simple writing mode for technical plans, documentation, comments, Markdown, prompts, reviews, progress updates, and handoffs that should be concise, plain, and load-bearing. Writing mode must not expand into architecture analysis unless the content requires it. Repository facts override speculative compatibility, migration, and scale concerns. Use `simple init`, `audit`, `plan`, `review`, `write`, or `check` for an explicit Simple workflow.
