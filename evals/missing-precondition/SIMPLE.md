# Simple

## Reality

- Stage and users: One trusted operator controls the editor integration.
- External consumers: None.
- Persistent production data: The platform-owned structured document must remain native and editable.
- Compatibility commitments: Preserve the visible reusable composition.
- Scale and failure consequences: Writes must fail closed when their result cannot be proved.

## Preserve

- The platform as the sole owner of document state.
- The visible nested renderer and reusable definition.

## Current boundary

- The supported API can edit native documents but cannot select this nested placement directly.
- The platform demonstrably stores and renders distinct structured overrides at arbitrary nesting depth.
- Public identity names a reusable definition and element, not the path through placed instances.

## Ordinary paths

- Use the platform's native structured-document editor and fresh readback.

## Proof

- Verify through the supported API and independently through the original nested renderer after reload.

## Reconsider when

- Move ownership only if no native address can expose the existing record reliably.
