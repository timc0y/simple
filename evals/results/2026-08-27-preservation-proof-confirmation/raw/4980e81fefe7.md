Ship the one-shot CLI. Do not ship the resident daemon.

First establish a cold-start profile that attributes the 180 ms: command startup, imports, generator/compiler import, remote operation, and output. Confirm the command only needs the generated JSON and that its location is stable.

Test the smallest change: move the JSON path constant to a leaf module, or derive it directly, so the command can read the JSON without importing the generator or compiler. Measure cold latency and verify command grammar, results, and completed task records remain unchanged.

If that succeeds, remove the daemon prototype, duplicate composition and routing, lazy loader, service installation/status/recovery commands, and parity tests.

A resident process becomes justified only if measurement shows a required capability needs live continuity across commands—such as an in-memory session or connection that cannot be represented as durable data—and its benefit outweighs the added operational surface.
