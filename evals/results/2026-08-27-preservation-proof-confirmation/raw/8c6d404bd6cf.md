Ship the one-shot CLI. Do not ship the resident daemon or lazy route loader.

First establish a cold-start profile: import timings, total command latency, and whether the generator/compiler import accounts for the ~180 ms. Also measure bundling before treating it as a remedy.

Test the smallest change first: move the generated JSON path constant into a dependency-free module, or pass the path directly where it is needed, so the command reads the JSON without importing the generator or compiler. Verify cold latency and unchanged command grammar, results, safety checks, and completed-task records.

If that succeeds, remove the daemon prototype, HTTP server, service installation, duplicate composition root and routes, recovery/status commands, parity tests, and lazy loader.

A resident process becomes justified only when measurement shows a required cross-command capability needs live continuity and cannot be represented as durable data—not merely to hide startup time.
