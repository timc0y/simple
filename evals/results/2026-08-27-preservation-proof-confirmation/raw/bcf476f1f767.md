Test the smallest change first: replace the generator import with a direct reference to the existing generated JSON path or data. Keep the command’s grammar, results, and durable task records unchanged. Run a cold-process latency comparison and the existing behavior checks.

If that succeeds, remove the generator and compiler from this command’s dependency path. The daemon prototype, HTTP server, service installation, second composition root, duplicate route table, lazy loader, parity tests, and service recovery commands should not ship; remove them if they exist only to hide this startup cost.

A resident process becomes justified only when a measured requirement needs continuity across commands—such as persistent in-memory state, connection reuse, or subscriptions—and that requirement cannot be represented as durable data or achieved through the ordinary one-shot path.
