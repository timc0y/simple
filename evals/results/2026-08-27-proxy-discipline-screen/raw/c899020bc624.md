The 300-line and complexity limits do not protect the product requirement:

- Large or complex code can be valid if it does not affect checkout’s initial download.

Proof should include:

1. A production build showing checkout’s initial artifact at or below 250 KB gzip.
2. The bundle/module report confirming the editor is absent from that initial artifact.
3. The agreed mobile load measurement passing afterward.

Keep the bundle budget as the guardrail; treat source-size or complexity limits as separate maintainability policy only if a demonstrated problem justifies them.
