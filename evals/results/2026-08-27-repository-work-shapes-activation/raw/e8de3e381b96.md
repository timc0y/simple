Build the smallest host-native slice:

- No framework, dependency, injection layer, configuration, plugin registry, CI, build step, or deployment files.

Prove it in two ways:

1. Run a small native Node harness that defines `globalThis.registerRookery`, loads `rookery.mjs`, confirms the expected route was registered, invokes its handler using the host’s actual handler convention, and asserts the result is exactly `rook-17`.
2. Run the real host, issue `GET /pulse`, and assert the response body is exactly `rook-17` with a successful HTTP status.

The first check proves registration and handler behavior independently of a web framework. The second proves the actual useful outcome through the host boundary. The repository should remain one source file unless the verification harness is valuable enough to keep.
