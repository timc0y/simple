```js
parseLedgerTag(undefined)
```

Affected callers:

- CSV importer: affected.
- JSON importer: affected.
- The other two import paths: unaffected because they always pass strings.

Preserved behaviour:

- Missing optional tag → `null`.
- Valid `team:item` string → existing parsed result.
- Malformed strings → existing validation error.
- Empty or otherwise invalid strings are not silently skipped.
