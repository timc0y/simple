## Material findings

1. `Current boundary` is false. It names `scripts/legacy-hook.mjs` and Codex only; that file does not exist. Both plugin manifests register [`scripts/hook.mjs`](/tmp/simple-repository-work-shapes/workspaces/52fe3de0b34d/scripts/hook.mjs), for Codex and Claude.

2. `Ordinary paths` and `Proof` are stale. `npm run verify` does not exist; the only declared script is `npm test`, matching the README. That test command currently discovers zero tests, so it does not independently prove hook behavior.

3. `Reality` overstates facts. The README calls this a published plugin and both manifests expose `ledger check`, contradicting “Public contracts: None.” The repository cannot establish “no external consumers” or “no persistent production data”; those should remain owner-confirmed unknowns rather than asserted facts.

4. `Preserve` is too vague to guide a change. “Current plugin behavior” should identify the observable behavior that matters: the `ledger check` plugin surface and registration of `session` and `write` hooks.

5. `Reconsider when` is not observable. “Becomes more important someday” provides no event an engineer can detect. It should name a concrete trigger, such as an external consumer, compatibility promise, retained data, or release requirement.

The profile has the required headings, but its structural validation is not ready because the repository lacks `AGENTS.md` and `CLAUDE.md`.
