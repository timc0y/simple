## Method

Luna and Terra each answered 2 cases under no-skill, current-Simple, and
candidate-Simple conditions. Luna and Terra graded the anonymous answers. Each grader
accepted the known pass and rejected the known fail before it graded the answers.

The code cases use `normalize-results.mjs` and `link-skill.mjs` from this repository.
The text cases use the observed credential-log dispute and an unsupported
compatibility request.

The subdirectories contain the condition map, raw answers, grade records, TSV results,
and normalized JSON. The final runner and both candidate diffs are in this directory.
The recorded commit does not contain the then-uncommitted case and candidate inputs, so
this record cannot prove their immutable source identity.
