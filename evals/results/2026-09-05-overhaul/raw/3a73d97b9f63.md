Filter destinations to those where:

- `status = active`
- `region = user_region`

Then select the eligible destination with the lowest `latency_ms`. If none remain, do not send the notification.

Proof case:

- A: inactive, same region, 10 ms
- B: active, same region, 50 ms

Filtering removes A, so B is selected. This guarantees inactive and out-of-region destinations can never receive notifications.
