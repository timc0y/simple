# Supplementary manual review contract

Recorded before any writing-context cell completed. This supplements, not replaces,
the frozen executable check. Review all six writing notes against the task's source
facts. A pass must preserve version v2.4.0, both exact command invocations, the rollback
boundary before database migration starts, an unknown migration duration, and no
claim that release has completed. The prose and JSON must agree. Accept equivalent
natural language for the boundary and unknown. Missing or contradictory facts fail;
formatting preference and a preferred phrase do not decide correctness.

For full-skill writing cells inspect completed command events for actual successful
reads of references/writing.md and SIMPLE.md. Record retrieval separately from prose
and JSON correctness. Short control has no writing reference; mark not applicable.
Prompted entrypoint/specialist reading is not automatic activation evidence.

For each previous-pass/candidate-fail case and repeat, read submitted source and
verifier failures. Distinguish violated task obligations from verifier false negatives,
timeouts and incomplete attempts. Preserve every original result and any supplementary
adjudication. No average improvement cancels a genuine individual regression.
