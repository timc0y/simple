The timeout is likely a symptom, not the cause: the form may be invalid when clicked, so submission is blocked and the request never starts.

I’ll check the form’s validity immediately before clicking and inspect any browser validation errors:

```js
const form = page.locator('form');

console.log(await form.evaluate(el => ({
  valid: el.checkValidity(),
  validationMessage: el.validationMessage,
  invalidFields: [...el.elements]
    .filter(field => !field.checkValidity())
    .map(field => ({
      name: field.name,
      value: field.value,
      message: field.validationMessage
    }))
})));
```

Then I’ll fix the missing or invalid field/setup before changing the wait or selector.
