The checkout page audit found 12 items:

- Coupon field accepts whitespace-only input (validation).
- Summary shows price before tax, while the payment button shows it after tax (copy mismatch).
- Address autocomplete drops the second address line on submit (data loss).
- Card form allows submission when the expiry date is in the past (validation).
- Returning with the back button after payment resubmits the order (duplicate charge risk).
- Promo banner pushes the payment button below the fold at 320px (layout).
- Screen reader announces the total twice (accessibility).
- Gift message field has no character limit (validation).
- Shipping options appear in a different order on repeat visits (layout).
- Error toast disappears after two seconds, before it can be read (accessibility).
- Postcode lookup calls the API on every keystroke (performance).
- Order confirmation email links to the staging domain (configuration).
